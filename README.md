## Примеры использования:

### 1. Модуль widget
1.1 Функция маскировки номера банковской карты или счета. Маску номера карты, где видны первые 6 цифр и последние 4 цифры остальные символы отображаются *.
```
 mask_account_card(card_or_account_number)
```
1.2 Функция принимает на вход строку с датой в формате "2024-03-11T02:26:18.671407"
    и возвращает строку с датой в формате "ДД.ММ.ГГГГ".
```
get_date(date)
```

### 2. Модуль masks
2.1 Функция маскировки номера банковской карты. Возвращает маску номера карты, где видны первые 6 цифр и последние 4 цифры остальные символы отображаются *.
```
get_mask_card_number(card_number)
```
2.2 Функция маскировки номера банковского счета. Возвращает маску номера счета, где видны только последние 4 цифры номера, а перед ними — две *.
```
get_mask_account(account_number)
```

### 3. Модуль processing
3.1 Функция принимает список словарей и опционально значение для ключа. Функция возвращает новый список словарей, содержащий только те словари,
        у которых ключ state соответствует указанному значению.
```
filter_by_state(list_, state = "EXECUTED")
```
3.2 Функция принимает список словарей и необязательный параметр, задающий порядок сортировки. Функция возвращает новый список, отсортированный по дате.
```
sort_by_date(date, order = True)
```
3.3 Функция, которая принимает список словарей с данными о банковских операциях и строку поиска.
    А возвращает список словарей, в описании которых есть данная строка.
```
process_bank_search(data, search)
```
3.4 Функция, которая будет принимать список словарей с данными о банковских операциях
    и список категорий операций. Возвращать словарь, в котором ключи — это названия категорий.
```
process_bank_operations(data, categories)
```

### 4. Модуль generators
4.1 Функция принимает на вход список словарей, представляющих транзакции. Возвращает генератор, который поочередно выдает транзакции, где валюта операции соответствует заданной.
```
filter_by_currency(transactions, currency)
```
4.2 Генератор, который принимает список словарей с транзакциями и возвращает описание каждой операции по очереди. Генератор возвращает описание каждой операции по очереди.
```
transaction_descriptions(transactions)
```
4.3 Генератор, который выдает номера банковских карт в формате XXXX_XXXX_XXXX_XXXX, где X — цифра номера карты.
```
card_number_generator(initial_values, final_values)
```

### 5. Модуль utils
5.1 Функция чтения json файла operations и преобразования его в словарь. Возвращает список словарей data из json файла operations.
```
open_file(file_)
```

### 6. Модуль external_api
Функция принимает на вход транзакцию и возвращает сумму транзакции в рублях.
    Если транзакция была в USD или EUR, происходит обращение к внешнему API
    для получения текущего курса валют и конвертации суммы операции в рубли. Возвращает конвертируемую валюту в рублях типа float
```
calculating_transaction_amount(operation)
```

### 7. Модуль transaction_reader
7.1 Функция открытия и чтения файла transactions.csv. Возвращает список словарей с данными из указанного файла.
```
csv_reader(file_path)
```
7.2 Функция открытия и чтения файла transactions_excel.xlsx. Возвращает список словарей с данными из указанного файла.
```
xlsx_reader(file_path)
```
